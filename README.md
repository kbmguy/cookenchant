# Cook Enchant (Fabric, Minecraft 26.3)

Put a pickaxe, sword, armor piece, bow, etc. in a furnace / blast furnace / smoker
with fuel. After 10 seconds it comes out with ONE random enchantment at level 255.
You can cook it again to stack another random enchant.

Build:  ./gradlew build     (needs JDK 25)
Jar:    build/libs/cookenchant-1.0.0.jar  -> put in .minecraft/mods with Fabric API 0.160.5+26.3
